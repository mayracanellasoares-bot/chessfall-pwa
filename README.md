# CHESSFALL Neon PWA

Puzzle de queda, fusão e evolução de peças de xadrez, pronto para publicação no GitHub Pages.

## Publicar no GitHub Pages

1. Envie todo o conteúdo desta pasta para a raiz do repositório.
2. No GitHub, abra **Settings > Pages**.
3. Em **Build and deployment**, selecione **Deploy from a branch**.
4. Escolha a branch `main`, pasta `/root`, e salve.

O jogo será instalável como PWA e continuará funcionando offline após o primeiro acesso.
